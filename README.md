# Ruizhang Yang — Academic Homepage

A lightweight static homepage prepared for GitHub Pages.

## Publish on GitHub Pages

1. Create or open your `USERNAME.github.io` repository.
2. Upload **all files and folders inside this package** to the repository root.
3. Keep this structure:
   - `index.html`
   - `styles.css`
   - `assets/Ruizhang_Yang_CV.pdf`
   - `assets/favicon.svg`
4. Commit to the branch used by GitHub Pages (usually `main`).
5. In **Settings → Pages**, select **Deploy from a branch**, `main`, `/ (root)`.
